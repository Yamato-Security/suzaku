# Можливості

* Кросплатформова підтримка: Windows, Linux, macOS.
* Розроблено на Rust для безпечної роботи з пам'яттю, швидкості та автономності.
* Аналіз журналів AWS CloudTrail, Azure/Entra ID/M365 і Google Workspace Reports API з нативним виявленням Sigma.
* Багатопотокове сканування `.json`, `.jsonl`, стиснених `.json.gz`, Parquet і підтримуваних [CSV CloudTrail з AWS Management Console](../getting-started/console-csv-input.md).
* Створення єдиних зручних для аналізу часових шкал для криміналістичних розслідувань та реагування на інциденти.
* Чудова вбудована підтримка сигнатур IoC, написаних у вигляді легких для читання/створення/редагування правил [Sigma](https://github.com/SigmaHQ/sigma) на основі YML. (Підтримуються кореляційні правила та всі модифікатори полів, окрім [expand](https://sigmahq.io/docs/basics/modifiers.html#expand).)
* Створення зведення про все використання API, метрик про зловмисника (вихідні IP-адреси, геолокація, використані регіони, агенти користувача тощо) для виявлення аномальної активності без опори на сигнатури.
* Збереження результатів у форматах CSV, JSON, JSONL і DuckDB.
