# 명령어 목록

## 분석 명령어:
* `aws-ct-metrics`: AWS CloudTrail 로그에서 메트릭을 생성합니다
  
## 요약 명령어:
* `aws-ct-summary`: 사용자 ARN의 활동 요약을 생성합니다

## DFIR 타임라인 명령어:
* `aws-ct-timeline`: AWS CloudTrail DFIR 타임라인을 생성합니다
* `azure-timeline`: Azure/Entra ID/M365 DFIR 타임라인을 생성합니다
* `gws-timeline`: Google Workspace DFIR 타임라인을 생성합니다

## 업데이트 명령어:
* `update-rules`: Sigma 탐지 규칙을 업데이트합니다

## 검색 명령어:
* `aws-ct-search`: AWS CloudTrail 로그 검색

## 일반 명령어:
* `help`: 명령어에 대한 도움말 메뉴를 출력합니다
